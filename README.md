# Kartik Manral — Portfolio

Personal portfolio site: aspiring APM, builder of buransh.ai, MediBook and Curio AI.

Plain HTML + CSS — no build step. Vercel serves `index.html` directly; `resume.pdf` is linked from the Download resume buttons.

## Updating
Edit `index.html` (or replace `resume.pdf`), then commit and push in GitHub Desktop — Vercel redeploys automatically.
